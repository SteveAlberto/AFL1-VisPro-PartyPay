# PartyPay

Aplikasi ini dibuat untuk memenuhi tugas **AFL 1: Production-Ready Flutter Application & Architecture Case Study**.

## Pemilihan Tema (Track)
Proyek ini mengadopsi **Track C: The Session Companion (Interactive Tool & Utility)**. 
PartyPay adalah aplikasi utilitas yang dirancang untuk membantu grup pertemanan atau fandom mengelola dan melacak patungan langganan layanan digital premium (seperti Steam Family, Netflix Premium, Spotify Family).
